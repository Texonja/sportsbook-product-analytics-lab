# Sportsbook Product Analytics Lab

### [⬇ Download for Windows — v1.1](https://github.com/Texonja/sportsbook-product-analytics-lab/releases/download/v1.1/Sportsbook-Lab-Windows.zip)

**Download the ZIP → Extract all → Double-click `START_APP.bat`.** The dashboard opens automatically in your browser after its startup check. The first start may take about a minute; keep the application window open while using it. Windows 10/11, 64-bit. Python, libraries and data are included; no installation or internet connection is needed to run it.

An interactive product analytics case study covering sportsbook conversion funnels, segmentation, friction detection and cohort retention, using **synthetic sportsbook data**.
